Final main experiment: stop on escape
Declared before new API requests, November 2, 2026

Scope
Exactly two existing benchmarks (two-stage op-amp and four-input AND), three feedback conditions (none, binary, full), and ten sessions per circuit/condition. Each session has at most ten attempts and stops immediately on its first electrically valid candidate receiving a usable is_trojan=false verdict. All ten sessions are new: earlier temperature-0.3 reviewer sessions cannot be combined with this temperature-0 protocol. No additional comparison, model experiment, log-assisted review, full-history modification or menu expansion is performed.

Session and pairing
A session is a fresh attack search with its own predeclared seed schedule, without history from other sessions. For each circuit/session index, the first candidate and fixed review are shared across the three feedback arms. If this first candidate escapes, all three arms stop at attempt one. Subsequent active arms each make their own requests. None always starts with no preceding candidate or feedback; binary and full retain only their own immediately preceding candidate and the corresponding Boolean/full review. Attacker temperature remains 0.3. Shared initial results and seeds make the arms paired, not independent circuit samples.

Fixed reviewer
The reviewer uses the unchanged netlist-only prompt, model gpt-4o-mini-2024-07-18, temperature 0.0, fixed seed 410001, and a 1600-token output cap. This output allowance is fixed before the run. It sees nominal function and candidate netlist, not ground truth, a clean reference, activation data, or simulation results. Each exact review request is evaluated once and its first outcome is cached across sessions and feedback arms. The key binds model, prompt, schema, nominal function, exact netlist, temperature, seed and output limit. Unusable outputs are cached too; they are neither detections nor escapes. Temperature zero alone does not guarantee deterministic API behavior; the cache makes this experiment's reviewer mapping fixed. Cached answers are not new API calls or independent judgments.

Physical checks
Reuse the unchanged electrically qualified menu: 81 op-amp and 54 AND configurations. Every actual generated candidate is simulated again under the original normal and activation tests. Clean simulation references for this execution are saved in its own directory. No archived simulation files are overwritten. Electrical validity means passing both normal-function and activation-effect thresholds. A generation failure, invalid rendering, failed electrical check or unusable review cannot count as an escape. No synthetic failures or trap options are added.

Order, counts and failures
Freeze all 560 possible actual generation tasks and their seeds before execution: 20 shared starts plus 540 possible follow-ups. The maximum condition-level count is 600 attempts, because shared starts appear in three arms. The run skips all subsequent tasks belonging to a stopped session; skipped tasks are recorded separately, never counted as attempted. Use a predetermined shuffle within each attempt index. No outcome-driven prompt tuning, seed changes, extra sessions, calibration reruns or retries of unusable outputs are allowed. The existing API transport recovery permits at most one separately identified retry after a transport failure, with the original billing reservation retained. Budget or infrastructure failures stop execution without declaring a completed experiment.

Results
For each circuit and feedback condition report successful sessions / 10. A secondary descriptive statistic is the first-success attempt among successful sessions, explicitly conditional on success; unsuccessful sessions use all ten attempts. At attempt k, the cumulative curve counts sessions whose first escape occurred at or before k. Each curve has fixed denominator ten and stays level after recorded successes without manufacturing later attempts. Do not use a pooled per-attempt escape fraction as the primary measure under early stopping. Report actual event counts, distinct netlists, unique review calls, cache uses and unusable outcomes separately. The same physical circuit can recur in different sessions.

Integrity and interpretation
Retain exact API inputs/responses, all simulator artifacts, source snapshots and hashes, a complete task disposition log, and offline independent recounts. Do not import old experiments or the supplementary detector comparison into current result tables. No new repeated clean/positive reviewer experiment or result-dependent acceptance gate is used. Existing clean-circuit qualification establishes the simulator baseline, not a new reviewer accuracy estimate. The study estimates success against this fixed cached reviewer on a finite synthetic circuit menu; it does not measure general false-positive rates, model learning, unrestricted Trojan synthesis, or the overall benefit of LLMs for hardware security. A null, tied or reversed feedback ordering remains a valid result.
